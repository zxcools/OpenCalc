# 期货开仓计算器 (OpenCalc)

本地运行的**期货 / 期权开仓风控计算工具**，零第三方运行时依赖，双击即用。数据完全保存在本机，不经过任何服务器。

## ✨ 功能特性

### 期权交易记录 (abe 策略)
- **左侧栏第三个 tab「📋 交易记录」**：完整记录期权买方代替期货开仓的逐笔操作 + 自动汇总
- **主表**：按开仓标的聚合，显示方向、开仓时间、是否平仓、平仓盈亏、平仓时间，按开仓时间倒序，最多 10 条，支持「显示全部」按钮
- **🔍 主表搜索框**：表格标题右侧，输入即筛选，只显示符合条件的记录（匹配范围与用法见下表）
- **只看未平仓开关**：一键筛选未平仓记录
- **右侧固定分栏详情**：点主表行后右侧展开持仓汇总 + 操作记录双表，不挡主表
- **持仓汇总自动计算**：按合约分组，仅算未平仓部分加权均价和剩余权利金
- **操作记录表**：开仓/平仓逐笔流水，按时间升序（最近在最下），含**备注**列（操作列前，超长悬停看全文）+ 修改/删除按钮
- **状态一眼可辨**：未平仓 = 绿 / 部分平仓 = 橙 / 已平仓 = 灰
- **监控池快照**：每次更新自动留痕，显示更新日期 + 历史快照可折叠查看
- **联动**：合约全部平仓后主表自动显示已平仓 + 平仓盈亏 + 最后平仓时间
- **导入/导出整合**：从资金曲线页挪到左侧栏下方联系作者上方，一键备份/恢复包含 资金曲线 + 期权交易记录 + 监控池快照 三部分
- **资金曲线「清除全部」隔离**：只清资金曲线表，不动交易记录和监控池

### 期货模式
- **风险额度可选**：0.5% / 1% / 1.5% / 2% / 3%，默认 1%，支持「设为默认」持久化
- **盈亏比决策**：止盈距离 ÷ 止损距离，≥ 1.5 建议参与，< 1.5 提示不参与
- **手数按风险金额倒推**：最大手数 = 开仓预算 ÷ 每手风险（止损价差 × 乘数），保证金仅作参考展示
- **🪜 阶梯止盈参考**：以止损价差为 1R，自动给出 2R / 3R / 4R / 5R 逐级止盈价与每手浮盈，分批止盈后一键参考下一档目标
- **🔄 切换品种自动清空**：换标的后开仓价 / 止损价 / 止盈价自动清空，免手动点击（同品种重选保留已填参数）
- **价格按 tick 步进**：内置 75 个品种的最小变动价位，上下箭头按 1 跳调节，非整数倍自动提示
- **内置品种乘数表**：覆盖全部活跃品种（含工业硅/碳酸锂/丁二烯橡胶/多晶硅等新品种）
- **🧹 一键清空价格**：开仓价/止损价/止盈价一键清空，重新输入更顺手

### 期权模式
- **风险额度可选**：0.5% / 1% / 1.5% / 2% / 3%，默认 3%，支持「设为默认」
- **买入方处理**：权利金全额占用资金，不占用保证金
- **🔄 切换品种自动清空**：换标的后开仓价（每手权利金）自动清空，免手动点击
- **搜索 + 常用标的**：支持代码/中文搜索，常用品种一键固定，悬停右上角 X 删除
- 开仓价 = 1 手期权价格（已含合约乘数）

### 资金曲线
- 月度明细 / 年度汇总，公式：本月盈亏 = 月末权益 - 月初权益 + 出入金
- **最新记录置顶显示**，年月/年份列**点击切换排序**（↓ 最新 / ↑ 最早）
- 多策略记录（abe / 威科夫）+ 汇总视图（缺失月份自动用最近月末延续）
- **累计提现卡片**：顶部实时显示 abe / 威科夫 / 汇总三档累计提现（按出金合计），一眼看出账户实际转出多少
- 图表展示（月收益 / 年盈亏，支持点击放大）
- **导出备份 / 导入恢复**（`.opcalc` 单文件），换电脑一键迁移
- **数据位置可自定义（内置文件夹浏览器）**：不用系统对话框，直接列盘符 + 目录，双击进入、选中回填；数据落在软件目录内时启动会**亮红点 + 顶部横幅**提醒，并提供**一键迁出**
- **💰 自动备份 + 一键恢复**：每次资金曲线 / 交易记录 / 监控池发生变动都自动存一份快照（保留最近 **10** 份）；弹窗里列出每份备份的时间与条数，点「恢复」即可退回那一刻
- 一键清除全部记录（双重确认 + 多步错误诊断，定位只读 / 文件锁 / 数据库损坏 / 网盘未同步）

### 其他
- 当前总权益支持「存为默认」，下次打开自动填入（单位：万元）；**期货 / 期权各存各的，互不影响**
- 录入 / 修改记录时**按 Enter 直接保存**
- 窗口可置顶（始终显示在其他窗口之上）
- 左侧竖条导航，默认占屏幕左半边
- 深色 / 浅色主题切换
- 左下角 💬 联系作者（知乎 + 微信/支付宝收款码）

### v50.31（2026-09-10）数据安全专项
- **🛡 数据搬到软件目录之外（重要）**：数据若存在软件自己的文件夹里，更新软件（替换/清理该文件夹）时会被一起删掉。现在启动就会检查，一旦发现数据在软件目录内会**亮红点 + 弹窗提醒**，并在「⚙ 数据位置」里提供**一键迁出**按钮
- **💾 每次数据变动自动备份**：新增 / 修改 / 删除交易记录、资金曲线、监控池，都会立刻往 `<数据目录>\backup\` 存一份带时间戳的快照（用 SQLite 备份接口，不会拿到写一半的库），自动保留最近 10 份；导入与「清除全部」会在操作**前**先备份，误删可退回
- **🔁 换数据目录不再丢交易记录（重要）**：此前切换数据位置只迁移资金曲线，交易记录与监控池会静默消失；现在三张表全部迁移，反复切换也不会翻倍
- **⚠️ 测试与真实数据彻底隔离（重要）**：测试脚本此前会直接连真实数据库并 `DELETE FROM` 三张表 —— 跑一次测试就把记录清空。现已改为全程使用临时库，并加了断言守护；E2E 也会先检查服务是否用测试目录启动，否则**拒绝运行**
- **🔌 可另起测试实例**：`OC_NO_TAKEOVER=1` + `OC_PORT` 可在不影响正在使用窗口的前提下另开一个实例

## 📁 数据存储

**数据目录查找顺序**（前一个存在就用前一个）：

1. 环境变量 `OC_DATA_DIR`（测试用）
2. 配置文件里的 `data_dir`（可在「⚙ 数据位置」里改）
3. 默认 `%APPDATA%\OpenCalc\data`

**各文件位置**：

| 内容 | 路径 |
|---|---|
| 资金曲线 + 交易记录 + 监控池（主库） | `<数据目录>\funds.db` |
| 自动备份快照（最近 10 份） | `<数据目录>\backup\funds_<时间戳>.db` |
| 用户设置（默认权益 / 风险额度 / 常用标的） | `%APPDATA%\OpenCalc\config.json` |

> ⚠️ **建议把数据目录设在软件目录之外**（如网盘同步文件夹）。放在软件自己的文件夹里，更新软件（替换/清理该文件夹）时会被一起删掉；软件启动检测到这种情况会亮红点提醒并支持一键迁出。

**`.opcalc` 与 `.db` 备份的区别**：

| | `.db` 自动备份 | `.opcalc` 手动导出 |
|---|---|---|
| 产生方式 | 每次增删改自动存 | 点「导出」生成 |
| 用途 | 本机退回某个时刻 | 换电脑 / 存档（跨机器） |
| 恢复方式 | 「⚙ 数据位置」→ 备份列表 → 恢复 | 侧栏「⬆ 导入备份」 |

数据不出本机；换电脑用「⬆ 导入备份」或设置相同的数据目录即可迁移。
