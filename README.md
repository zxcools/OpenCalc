# 期货开仓计算器 (OpenCalc)

本地运行的**期货 / 期权买方 / 期权双买开仓风控 · 交易记录 · 资金曲线**工具。零第三方依赖、双击即用，数据只存本机，不经过任何服务器。

## ✨ 主要功能

### 🧮 开仓计算器

<img width="100%" src="docs/screenshots/calc.png" alt="开仓计算器（期货模式）">

- 三个模式：**期货** / **期权买方** / **期权双买**，参数各自独立、各自记忆（三个模式排成一行）
- 结果区按模式隔离：切到别的模式立刻清空，切回上次算过的模式自动恢复它自己的结果
- 风险额度 0.5% / 1% / 1.5% / 2% / 3%（默认期货 1%、期权 3%），可设为默认
- 期货手数 = 开仓预算 ÷ 每手风险（止损价差 × 乘数）；保证金只作参考展示
- 期权买方：权利金全额占用、不占保证金；开仓价 = 1 手价格（已含乘数）
- 🆕 **期权双买**：call + put 两条腿，输入**期权价格**（行情里的单吨/单点报价，与每手权利金自动换算）+ **当前 IV / IV 百分位**（留档供复盘），
  手数按 **delta 中性**配比（call手数 × |call delta| = put手数 × |put delta|），合计权利金不超预算；
  止盈目标价按**同一价格口径**给出总价值涨到 **2 / 3 / 4 / 5 倍权利金**时两腿各自的价位（涨看 call 腿、跌看 put 腿）
  - put 的 delta 一边输就自动带「-」；delta 统一保留 **4 位小数**
  - 🎨 Call（看涨）**红** / Put（看跌）**青**：两腿参数各是一张带色卡片，结果里的手数卡、止盈目标价位表两列也都按腿上色，不容易看串
- 盈亏比决策：止盈距离 ÷ 止损距离，低于 1.5 提示不参与；手数不足 1 手直接判「不开仓」
- 🪜 **阶梯止盈参考**：以止损价差为 1R，给出 2R~5R 逐级止盈价（按最小变动价位取整，挂单可直接成交）与每档浮盈
- 内置 **75 个品种**的合约乘数 + 最小变动价位；价格按 1 跳步进并校验整数倍
- 最近方案：三个模式**各存最近 10 组**，一键调出重算；参数按**原始输入**留档（不做四舍五入，delta 的 4 位小数原样保留）；卡片右侧 ✕ 可单条删除（删除前二次确认）
- 📥 **加入记录**：把当前参数 + 测算结果一键写入交易记录，并直接跳转到那条记录（不弹提示框）；期货模式上方填了**合约年月**（如 2610），写入的合约与标的都带年月（`rb2610`）
- 🔄 **换品种自动清空**：切到别的标的时该模式的开仓参数与测算结果一起归零，避免拿旧品种的行权价 / 权利金当成新品种的参数；同品种重选不会误清

### 📋 交易记录（期权买方 / 期权双买 / 期货 三个入口，数据互相隔离）

<img width="100%" src="docs/screenshots/trades-futures.png" alt="交易记录 · 期货模式">

- 主表按**「标的 + 批次」**聚合，同品种多次开仓各自成一条：方向 / 开仓时间 / 是否平仓 / 平仓盈亏 / 平仓时间；默认显示 10 条，可展开全部
  - 期权双买的开仓标的会带上**合约年月**（如 `lc 2611`），下方便是两条腿的完整合约
  - 双买记录的「价格」= **期权价格**（与行情报价、止盈目标价同一口径），「权利金」= **每手金额**（期权价格 × 合约乘数），两者别混
- 期权模式（期权买方 / 期权双买）新建开仓时，**权利金自动 = 开仓价 × 合约乘数 × 数量**（下面小字写明算式），也可以手改；期货模式该字段是保证金，不自动算
- **顶部战绩卡**：累计盈亏 / 胜率 / 已平仓（附持仓中）/ **盈亏比 · 净盈亏比** / 平均盈亏 —— 口径是主表每条记录（一条 = 一笔），可一键隐藏并记住选择
- **手续费与净盈亏**：工具栏可切「交易所 + 0.01」/「不计算」（两个选项直接平铺，不用展开下拉框）；主表有**净盈亏**列（= 平仓盈亏 − 手续费），详情的操作记录里逐笔显示手续费。**平今 / 平昨按开平仓时间自动判，也可以在平仓时手动指定**（自动 / 平今 / 平昨 三选一）—— 有些品种这两档费率差很多（如棉花平今 0、平昨 4.3 元/手）
- **平仓盈亏自动算**（填平仓价就出来，不含手续费）：=(平仓价 − 开仓均价) × 方向 × 合约乘数 × 平仓手数；仍然可以手改，手改的值不会被覆盖（只有再动平仓价 / 平仓数量 / 合约时才重算）；提示行会写明完整算式让你对着核
- 搜索框：匹配 标的 / 合约 / 方向 / 状态 / 日期 / 盈亏，多个关键词空格分隔 = 全部命中
- 右侧详情：**顶部给出这一批的「手续费合计 / 净盈亏」**；持仓汇总（只算未平仓部分的加权均价）+ 操作记录（备注、合约筛选、修改、删除），FIFO 扣减
  - **点合约代码即可复制**（持仓汇总与操作记录里都能点，复制成功底部有提示）
- 平仓数量超额即时拦截；每条记录的详情内容（状态、盈亏、操作、复盘）**完全独立**，不与其他记录掺和
- 期货模式专属：初次止损 / 止盈、开仓测算结果卡、阶梯止盈方块；双买记录里一次操作写入两条腿（同批次归为一条记录）
  - 双买模式在主表点「➕ 新建开仓」会打开**两腿专用弹窗**（一次填 call / put 的行权价·delta·期权价格·手数 + IV / IV 百分位，权利金按开仓价自动算）；
    详情面板里的「新建开仓」仍是**单腿**录入（加仓/补录用）
- **复盘笔记**：三个模式都有，归属跟着「这条记录」走（同品种别的记录看不到）
- 期权记录在详情顶部显示**开仓时的 IV / IV 百分位**（编辑开仓不会被抹掉）
- 双买记录的详情里，「当前持仓」上方有**止盈价测算**：按持仓总权利金给出 2 / 3 / 4 / 5 倍时两腿各自的期权价格目标（涨到 Call 目标平 call、跌到 Put 目标平 put）；Call 列**红**、Put 列**青**一眼分清，从计算器加入的和手动新建的都一样现算，平仓后按剩余持仓自动更新
- 监控池快照（期货 / 期权买方分开保存，保留历史可查）；**期权双买不设监控池**

点开任意一条记录，右侧浮出**这一条自己的**详情 —— 状态 / 持仓 / 操作记录 / 测算结果 / 复盘互不干扰：

## 🚀 快速开始

**直接运行（推荐）**：下载 `dist/OpenCalc.exe` 双击即可（Windows 10/11，无需任何环境）。

**源码运行**（需 Python 3.8+，仅标准库）：

```bash
python main.py
```

**自己打包 exe**：

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name OpenCalc --icon icon.ico \
  --add-data "icon.ico;." --add-data "chart.min.js;." \
  --add-data "assets/qrcode-wechat.png;assets" --add-data "assets/qrcode-alipay.png;assets" \
  main.py
```

## 📁 数据存储

数据目录查找顺序（前面的优先）：`OC_DATA_DIR` 环境变量 → 配置里的 `data_dir` → 默认 `%APPDATA%\OpenCalc\data`。

| 内容 | 路径 |
|---|---|
| 资金曲线 + 三种模式的交易记录 + 监控池 + 复盘（主库） | `<数据目录>\funds.db` |
| 自动备份快照（最近 10 份） | `<数据目录>\backup\funds_<时间戳>.db` |
| 用户设置（默认权益 / 风险额度 / 常用标的） | `%APPDATA%\OpenCalc\config.json` |
| 计算器「最近方案」 | 浏览器 localStorage（随 `.opcalc` 一起打包） |

> ⚠️ **建议把数据目录设在软件目录之外**（如网盘同步文件夹）。放在软件自己的文件夹里，更新软件时会跟着被删 —— 启动检测到会亮红点提醒并提供一键迁出。

| | `.db` 自动备份 | `.opcalc` 手动导出 |
|---|---|---|
| 产生方式 | 每次增删改自动存 | 点「⬆ 导出」生成 |
| 用途 | 本机退回某个时刻 | 换电脑 / 长期存档 |
| 恢复方式 | 「⚙ 数据位置」→ 备份列表 → 恢复 | 侧栏「⬇ 导入备份」 |
| 内容 | 整库 | 资金曲线 + 三种模式交易记录 + 监控池 + 复盘 + 最近方案 |

> 备份完整性有专门的往返验证脚本：`python tools/backup_roundtrip.py`（起两个临时库，导出→导入→逐表核对，不碰真实数据）。

## 🔄 发版（维护者）

「检查更新」读的是仓库 `main` 分支的 `version.json`，发版三步：

1. 改 `main.py` 的 `APP_VERSION`（整数，比用户本机大才会提示更新）
2. 更新 `version.json`：`version` / `version_name` / `date` / `url` / `sha256` / `notes`
   - `sha256` 留空则不校验；填了必须完全匹配（重新打包后要重算）
   - `url` 填相对路径时按 `https://raw.githubusercontent.com/zxcools/OpenCalc/main/` 拼接
3. 打包并把 `dist/OpenCalc.exe` 一起提交推送 —— **`version.json` 与 exe 必须同时是最新的**

- 🛠 **本轮以修复为主**（按代码审查结果逐条处理），另加了下面的交易日历
- 📅 **接入最小交易日历**：夜盘（21:00 后）属于**下一个交易日**，以前只做「+1 天」—— 周五 21:30 开的仓被算成**周六**，跟「下周一早盘平」判成两个交易日 → **平今被误判成平昨**，手续费多收。现在会跳到**下一个真正的交易日**（跳周六周日 + 跳法定节假日，含春节连休 9 天这类长假）

  - 节假日表每年要更新一次（国务院办公厅每年 11 月前后发布次年安排）

- 🔧 **「持仓中」不再恒为 0**：统计区间选「按平仓时间」时，未平仓记录因为没有平仓日会被整条滤掉，导致「持仓中」一直显示 0（跟旁边「未平仓不计入」的说明自相矛盾）。现在**持仓数始终按全部记录算**，卡片小字会写明口径（「持仓中 1（全部） · 区间内 3 条」）
